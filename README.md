# ERLC-Discord-Bot
Free and open source ERLC Discord Server bot with GUI. IN TESTING

Instructions on how to run.
1. Install python if not already installed.
2. Open app_bot_copy in terminal.
3. Run ```pip install -r requirements.txt```
4. If that works, ```run python main.py``` or ```python3 main.py```
5. Configure everything in GUI.
